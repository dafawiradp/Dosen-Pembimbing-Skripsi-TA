# Data Analysis

## Integritas data

Gunakan data mentah sebagai artefak yang tidak berubah. Buat salinan kerja untuk transformasi. Catat setiap perubahan pada log analisis.

## Sebelum analisis

Verifikasi:

- tipe variabel;
- rentang nilai;
- satuan;
- nilai hilang;
- duplikasi;
- pencatatan respons;
- pencatatan kategori;
- distribusi variabel.

Jangan mengisi nilai hilang atau menghapus outlier tanpa persetujuan pengguna dan dokumen keputusan. Jika pembenaran tidak tersedia, laporkan sebagai ketidakpastian.

## Pemilihan metode

Sesuaikan metode dengan tujuan, jenis variabel, desain, distribusi, independensi observasi, dan asumsi. Tampilkan hasil ujian asumsi beserta dampaknya. Jangan mengganti metode hanya untuk memperoleh hasil signifikan.

## Pelaporan

Laporkan ukuran efek, interval kepercayaan, ukuran sampel, metode, dan batasan selain nilai p jika relevan. Bedakan signifikansi statistik dari signifikansi praktis.

## Jejak kerja

Untuk setiap perhitungan, catat:

- input;
- transformasi;
- rumus/metode;
- parameter;
- output;
- interpretasi;
- keterbatasan.
