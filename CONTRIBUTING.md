# Contributing

## Aturan perubahan

- `SKILL.md` adalah sumber instruksi utama.
- Perubahan akademik substantif perlu diperbarui pada referensi yang relevan.
- Adapter hanya boleh berisi pemasangan, pemanggilan, dan keterbatasan platform.
- Jangan menambahkan salinan aturan akademik ke setiap adapter.
- Jangan menambahkan metadata proprietary pada `SKILL.md`.

## Alur kontribusi

1. buat branch;
2. ubah file terkendali;
3. jalankan `python scripts/validate_skill.py`;
4. tambahkan atau perbarui test case yang relevan;
5. perbarui `CHANGELOG.md`;
6. buka pull request.

## Standar isi

- bedakan fakta, asumsi, interpretasi, dan hipotesis;
- jangan menambahkan sumber atau DOI tanpa verifikasi;
- jangan mengubah data penelitian atau menyembunyikan ketidakpastian;
- pertahankan bahasa Indonesia yang profesional;
- gunakan nama file dan tautan relatif yang jelas.
